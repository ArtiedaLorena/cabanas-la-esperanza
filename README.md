# Cabañas San Martín

Landing de ejemplo para un complejo de cabañas en Villa Larca, San Luis.  
Datos de contacto, unidades y fotos son **ficticios**.

[Vite](https://vite.dev/) · [React](https://react.dev/) · [TypeScript](https://www.typescriptlang.org/) · [Tailwind CSS v4](https://tailwindcss.com/)

## Cómo correrlo

```bash
npm install
npm run dev
```

Abrí [http://localhost:5173/](http://localhost:5173/).

```bash
npm run build
npm run preview
```

El copy vive en `src/data/site.ts`.
